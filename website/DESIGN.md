# 留白官网设计方向

为专注阅读和写作的人设计的产品官网。极简、安静，近乎纯白的空间承托缓慢起伏的纸面。

- DESIGN_VARIANCE: 5，首屏用少量文字与偏置纸面形成平衡。
- MOTION_INTENSITY: 3，3D 纸张是产品“书写空间”的隐喻；不使用滚动劫持和夸张入场。
- VISUAL_DENSITY: 1，大量空白，三个主段落，没有功能卡片墙。
- 自有视觉语言：原生 CSS + Vite + Three.js，非某个官方 UI 设计系统。
- 色彩：石墨灰、微暖中性白；深色使用同一组相对明度，不切换章节主题。
- 字体：本机 UI 中文字体，英文自托管 Manrope；正文保证对比，辅助文字不低于 4.5:1。
- 几何：按钮使用细圆角，产品截图保持真实窗口比例；不重绘应用截图。
- 分层：正文 0，艺术场景 0，导航 10，下载对话框使用原生 dialog 顶层。
- 性能：限制绘图像素比和帧率，画面离开视口/后台时暂停，尊重 reduced motion。
- 下载：官网同域提供四个安装包；分别标注 macOS 1.2.1 / Windows 1.2.0，校验完整性。
